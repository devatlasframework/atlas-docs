# guides

Prose developer guides, meant to explain the _why_ and the workflows that the reference in
[`../api/openapi.yaml`](../api/openapi.yaml) cannot.

**None have been written yet.** Until they are, the contract itself is the documentation: each
operation says who may call it, what it needs and how it fails, and
[`../changelog/CHANGELOG.md`](../changelog/CHANGELOG.md) explains each surface as it arrived,
including API keys and scopes, rate-limit headers, sign-in on behalf and webhook signatures.
